# 实现与验证

## 接入方式

安装器校验 Bandizip 主程序版本、x64 架构和原引擎 SHA-256，备份原引擎后安装同名转发 DLL。主程序、文件关联、原有右键菜单和密码管理器数据不修改。扩展只在兼容的 `Bandizip.exe` 内启用；Explorer 等宿主只转发调用，不运行密码匹配。

兼容引擎 SHA-256：`868a4b870f43024688d4e9c74d9c4e42bc7f4e439972a93059ee95f4a2dbb135`。

保留引擎全部 82 个虚表槽和 RTTI，替换文件打开、密码回调及提取入口。密码按管理器顺序去重尝试；每个文件分别记录已确认的密码。默认单次提取；手动开启完整预校验时先向丢弃流验证选中的内容。全部密码失败时保留压缩包，汇总失败原因；CRC 错误注明也可能是数据损坏。

窗口拖动会在调用提取接口前询问密码。仅在固定调用位置及指令指纹同时匹配、且能读取已存密码时，将该次预先询问交由实际提取时的密码回调处理。其他加密状态查询返回真实结果；不修改主程序或文件的加密标志。

提醒线程仅在 Bandizip 进程内临时运行；进程退出前完成待显示提醒，没有常驻程序、服务或计划任务。不同 Bandizip 进程分别汇总，记录文件通过互斥锁协调写入。

## 1.2.0 修复

- 默认关闭旧版自动预校验，避免每次先校验再解压；选项明确提示额外耗时。
- 接入窗口拖动前的原生密码询问，实际提取仍逐项尝试保存的密码。
- 修复多文件预校验消费原生选择列表后，正式提取扩大到整个压缩包的问题。
- 写入文件夹时遇到候选密码误命中，只校验失败文件并恢复未完成的选择项；已成功文件不重复写出。重试前确认失败输出的文件身份，防止覆盖随后被替换的文件。
- 修正取消时原引擎返回成功造成的成功记录；取消、跳过或错误均禁止自动回收。
- “恢复原组件”改名为“卸载插件”，新增默认关闭的回收站选项。

回收前要求所有普通文件均成功写出，校验源文件 ID、卷号、大小和修改时间。RAR 使用实际读取的分卷；7z 使用校验过的起始头确定末尾，ZIP 使用尾部卷号确定分卷数量，排除引擎额外枚举的相近文件。Shell 操作只允许回收，拒绝永久删除；仍被引擎占用时延迟到关闭后处理。部分回收失败会记录已回收数量和错误，未回收的源文件保留。

## 回归覆盖

1.2.0 本机验证：41 项单元检查、85 项隔离集成检查全部通过。

集成测试使用 Bandizip 原程序的隔离副本、隔离注册表和虚构密码；测试后核验真实安装文件未变化。回收测试只操作测试文件，结束后从回收站恢复这些文件。

- 密码格式、Unicode、去重、主密码回退、损坏数据、Blowfish 已知向量、SHA-256 和文件写入。
- 普通 ZIP、加密 ZIP、ZIP 密码检查碰撞、7z 加密文件头、RAR3/RAR5、中文密码。
- 原生打开压缩包、经典及 Windows 11 右键菜单、批量解压、选中文件、同包不同密码。
- 连续 5 个压缩包、共 200 个文件的单次提取及完整预校验；旧版设置不会自动开启预校验。
- ZIP 弱密码误命中的定向重试、自动重命名模式不产生重复输出、部分选择范围不扩大。
- 普通及加密 ZIP 回收、选中部分文件和跳过覆盖时保留、7z/ZIP/RAR3/RAR5 分卷、紧邻编号的额外文件保留。
- 密码耗尽、压缩包损坏、失败提醒、保留源文件、记录不含密码。
- 安装、重复安装、包体篡改拒绝、缺失记录/引擎恢复、卸载、损坏备份拒绝及保留更新后的引擎。

GUI 预览由程序离屏绘制，使用合成数据；不是用户桌面截图。CI 在 Windows 上构建并运行单元与隐私检查，不下载或分发 Bandizip。完整集成测试需自行提供兼容安装。

## 边界

这是固定版本的非官方扩展，没有稳定的官方插件 API。版本或引擎不匹配时不启用匹配。窗口拖出加密 ZIP 已由人工操作确认，日志验证了逐项匹配和实际提取成功；自动测试不模拟拖动。未验证 Windows ARM64 仿真、所有多卷/固实组合及高并发极端情形；测试通过不表示覆盖所有输入。

密码管理器设置主密码、数据格式未知或读取失败时保留原生密码窗口。`bz.exe`、自解压程序及内存流入口不启用自动匹配。单次提取使用原生校验，失败时可能留下部分输出。定向重试限于能确认失败输出身份的文件夹提取；流、单文件预览或无法确认输出身份时可用完整预校验。回收不能确认完整范围时保留原文件；非 7z 的 `.001` 通用分段暂不自动回收。

GUI 声明 Windows 10/11 兼容性；本次完整原生菜单回归在 Windows 11 x64 进行。UAC 真实安装交互及跨显示器 DPI 切换未纳入自动集成测试。安装/恢复须关闭 Bandizip；Explorer 正在占用的退役组件可能暂留在安装目录，原引擎备份保留用于恢复。

## 发布隐私

发布仅包含源码、合成界面图、本项目二进制及必要许可证。检查本地账户禁词、个人绝对路径、令牌模式及 PE 调试目录；不上传原始测试日志、注册表、密码、Bandizip 文件或真实解压记录。Git 提交使用通用维护者身份。

`BZAP_PRIVATE_TERMS` 可在本机提供分号分隔的额外检查词，不写入仓库。扫描是发布检查，不是对任意潜在敏感信息的自动证明。
